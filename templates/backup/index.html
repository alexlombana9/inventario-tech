Informacion
  • Descargar: genera un dump SQL completo y lo descarga al navegador.
  • Backup Local: guarda el dump en la carpeta backups/ del servidor para uso futuro.
  • Subir: permite subir un archivo .sql previamente descargado para almacenarlo en el servidor.
  • Restaurar: ejecuta las sentencias SQL del backup seleccionado sobre la base de datos actual.
  • Precaucion: restaurar un backup puede sobrescribir datos actuales. Siempre crea un backup antes de restaurar.
