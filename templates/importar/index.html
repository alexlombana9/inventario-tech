Cargar Archivo
Tamano maximo: 10 MB. La primera fila debe contener los encabezados.
Consejos para importar
  • Puede usar su propio archivo Excel, solo asegurese de que los encabezados (primera fila) coincidan con los nombres de columna indicados.
  • No importa el orden de las columnas, el sistema las detecta por nombre.
  • Las columnas opcionales se pueden omitir, el sistema usara valores por defecto.
  • Si un producto con el mismo codigo ya existe, se actualiza en vez de duplicarse.
  • Orden recomendado de importacion: Categorias → Proveedores → Productos → Clientes → Acreedores → Deudas → Facturas.
  • Las fechas se aceptan en formatos: 2026-01-15, 15/01/2026, 15-01-2026.
